# 不依赖 KW26 的指数空间构造，以及本轮比较的理论边界

本文件给出本轮实验中 `greedy-*` 方法的完整算法依据。它不修改 `../v3/main.tex`，不声称下述标准贪心与分块技巧为首次出现。研究结论是：**允许指数空间以后，确定性 `O*((3/2)^n)` 不必依赖 KW26；KW 对现有主稿最关键的价值，是其特别适合小空间实现的覆盖与归属结构。**

以下普通线性代数复杂度按二元位操作计，`O*` 只省略多项式。实际 C++ 在 `n≤40` 时以一个 64 位机器字保存一行，实测的多项式成本会明显不同。

## 1. 把覆盖作为一个可替换的接口

保留 BH13 的局部度公式。设输入去对角后为 `B`，人工对角为 `A=B+diag(c+1)`。目标为

\[
H(B)=\bigoplus_{x\ne0,\;x_i((Bx)_i+c_i)=0\;(i\in[n])}f_A(\operatorname{supp}x).
\]

`f_A(X)` 是 BH13 的 P3 仿射系统的解数奇偶，可用相容性与唯一性测试计算。人工对角同时改变可行集合和权重；P2 解数奇偶本身不是答案。来源：[BH13，§2 与 §4.1](https://arxiv.org/abs/1301.7250v2)。

给三种合法状态 `(0,0),(1,0),(0,1)` 编号为 `0,1,2`。任取一个三元空间的二元子立方体覆盖 `Q`。中心 `q` 禁止状态 `q_i`，在每坐标余下的两个状态上进行如下参数化：

| 禁止状态 | `(x_i,y_i)` | `M_q` 第 i 列 | 对 `d_q` 的贡献 |
|---|---|---|---|
| 0 | `(1+z_i,z_i)` | `B_i+e_i` | `B_i` |
| 1 | `(0,z_i)` | `e_i` | 0 |
| 2 | `(z_i,0)` | `B_i` | 0 |

于是 `Bx+y=c` 等价于 `M_q z=c+d_q`，且对固定 `q,c`，每个 `z` 唯一对应一个 `x`。记中心数为 `M`，所有仿射系统的总访问数为

\[
V(c)=\sum_{q\in Q}\#\{z:M_qz=c+d_q\}.
\]

每个中心有 `2^n` 个参数向量，每个向量恰好指定一个 `c`，故 **对任何完整覆盖** 都有

\[
\mathbb E_c V(c)=M.
\]

这条恒等式并不要求覆盖来自一个图。固定 `c` 的前 `ℓ` 位时，条件期望为

\[
2^{-(n-\ell)}\sum_q Z_q(c_{\le\ell}),
\quad
Z_q=\begin{cases}2^{n-\operatorname{rank}M_q[1:\ell,:]},&\text{相容},\\0,&\text{不相容}.\end{cases}
\]

逐位选择较小分子，得到确定性 `V(c)≤M`。这是 BH13 自环条件期望思想在覆盖接口上的应用，不应把条件期望本身写成本项目首次提出。

接下来有两种完全通用的去重方式：

1. 为每个状态指定覆盖它的第一个中心，只在该中心计入贡献。
2. 收集所有被访问的 `x`，排序、唯一化，再计算每个非空 `x` 的 P3。

第二种方式无需覆盖的专用 ownership 证明，但需要存储访问列表。排序的比较数为 `O(V log V)`，每次比较至多 `O(n)` 位；在 `M=poly(n)(3/2)^n`、`V≤M` 时为 `O(n²M)` 位时间，低于普通 P3 的 `O(n³M)`。

## 2. 四块普通贪心覆盖

令 `a=3/2`。在一块 `b` 个坐标上，所有 `3^b` 个中心均允许选取，每个中心覆盖 `2^b` 个状态。

如果当前还有 `u` 个未覆盖状态，则各中心新覆盖数量的平均值是 `u(2/3)^b=u/a^b`，因为每个状态被恰好 `2^b` 个中心覆盖。选取新覆盖数量最大的中心，可使未覆盖量从 `u` 降到至多 `u(1-a^{-b})`。因此至多

\[
T_b\le\lceil b\ln(3)\,a^b\rceil+1=O(b a^b)
\]

步就能覆盖全部状态。固定最小编号打破平局，整个构造确定。此处仅使用经典集合覆盖的平均计数，不使用 KW 的常数因子覆盖定理。

### 如何真的在足够快的时间构造

把未覆盖指示数组记为 `u∈{0,1}^{3^b}`。全部中心的新覆盖数量是

\[
w=(J_3-I_3)^{\otimes b}u.
\]

对每个坐标进行一次三元蝶形变换

\[
(r,s,t)\longmapsto(s+t,r+t,r+s).
\]

一次变换的总成本为 `O(b3^b)` 次长度 `O(b)` 的整数加法，即 `O(b²3^b)` 位操作。扫描最大值并标记该中心的 `2^b` 个状态，也在这一界以内。在某状态第一次被覆盖时，保存该中心的编号，即得到通用 ownership 表。

全部 `O(b a^b)` 步的构造时间为

\[
O\bigl(b^3(9/2)^b\bigr),
\]

空间为 `O(b3^b)` 位。这里没有把更新一个指数长度数组当成常数时间。

把 `n` 个坐标分成四个尽可能等大的块，分别构造后取乘积。于是

\[
M=\prod_{j=1}^4 T_{b_j}=O(n^4a^n).
\]

构造的指数因子为

\[
(9/2)^{n/4}\approx1.456476^n < 1.5^n.
\]

所以全部构造时间可由 `O(a^n)` 吸收，包含其多项式因子；四块取整只改变常数。保存局部中心列表与 ownership 表后，全局中心可用混合进位计数器生成，无须保存整个乘积。给定状态，查四张 ownership 表即可确定唯一全局中心。

### 两个确定性资源结论

直接对每个候选对角前缀、每个中心重新消元，得到

\[
\boxed{T(n)=O(n^8a^n),\qquad S(n)=O(n3^{\lceil n/4\rceil})\text{ 位}.}
\]

时间的主项是 `n` 次前缀决策、`M=O(n^4a^n)` 个系统以及每次 `O(n³)` 消元。最终 `V≤M`，所以最终枚举和 P3 为 `O(n³M)`，不超过上述主项。实现对应 `greedy-det-lowmem`；这里的 lowmem 指相对完整前缀缓存的空间较小，**仍是指数空间**。

若像 `v3-ex2/3` 那样保存所有中心的行前缀依赖，则得到

\[
\boxed{T(n)=O(n^7a^n),\qquad S(n)=O(n^6a^n)\text{ 位}.}
\]

预处理每个矩阵为 `O(n³)`。每条依赖保存 `O(n)` 位，每中心总计 `O(n²)` 位。逐位选对角成本 `O(n²M)`；预处理、最终 P3 的 `O(n³M)` 成为主项。实现对应 `greedy-det-owner`、`greedy-det-sort`。

因此，这是一条**严格保留 `O*(1.5^n)`、确定性、但使用指数空间**的构造。其独立性是相对 KW26：BH13 的 P2/P3、自环思想以及三种局部线性化的既有背景仍须引用。

## 3. 这对论文定位的影响

一种更清楚的结果层次是：先陈述一个“覆盖到带权纤维求和”的通用算法接口；普通贪心四块给出独立于 KW 的指数空间实现；再利用 KW26 的图构造和可算法化一致性，把空间降为多项式，并改善多项式因子。

这个层次能解释本项目如何独立完成算法闭环，也能精准说明 KW 的额外价值。它**没有**证明 KW 多项式空间版本可以直接由普通贪心替代：普通贪心的局部覆盖密度损失是 `O(b)`，而 KW 是常数；同时普通贪心存储 `3^b` 表项。把 `b` 缩到 `O(log n)`，虽然局部表变成多项式，乘积覆盖中的密度损失一般只给出

\[
a^n\exp\!\left(O\!\left(\frac{n\log\log n}{\log n}\right)\right),
\]

这不是 `O*(a^n)`。不能省略这一差别。

推荐把四块构造作为可选的独立性命题或补充材料；是否放进主文，应取决于论文篇幅与审稿人的关注点。不要把标准贪心覆盖本身写成新的组合定理，也不要凭本轮有限检索声称“首次不依赖 KW 的算法”。

## 5. 直接仿射分支的独立性及其限制

对 `x_i v_i=0`，在当前仿射空间上，把解分成两个不交分支：

\[
x_i=0,\qquad\text{或者}\qquad x_i=1,\;v_i=0.
\]

若限制后的两个形式独立，两个子空间的维数分别下降 1 和 2；若相关，则可消去为线性约束、恒真或矛盾。先做这些线性传播，再用回滚消元递归；最终整个叶仿射空间均合法时流式枚举。

搜索树的维数分析给出黄金比例型递推，另外还须支付输出量 `K`：`poly(n)(φ^n+K)`。随机自环使 `E K=a^n`，因此期望 `O*(φ^n)`。固定任意对角时，不能忽略可能为 `2^n` 的叶空间输出。

该方法不依赖 KW，正确性解释简单，也不需要去重。然而本项目 `command2` 已经探索过相同的分支原理；它不是本轮首次提出。它也没有给出 `1.5^n` 的一般图证明。本轮新增的是统一 C++ 实现、整条 P2+P3 的远程比较。

## 6. 空间与并行承诺需要分开写

随机时间不等于随机答案。所有 LV 行输出均精确；随机性只影响运行时间与某些版本的内存。

对本轮“随机辅助图 + 两块缓存 + ownership”的实现，局部中心缓存的**最坏**空间为 `O(n2^(n/2))` 位，期望为 `O(n a^(n/2))`；图本身极端退化时可能有很多偶诱导集合。不能把期望中心数当成每次运行都满足的上界。

随机版排序去重的访问数组空间与实际 `V(c)` 成正比。其期望为 `poly(n)a^n`，最坏空间并没有同一个保证。确定化到 `V≤M` 后，排序数组才有确定的 `O(nM)` 位界。

多核可独立求解各中心、计算贡献并作 XOR 归约；逐位确定 `c` 仍有 `n` 个适应性阶段。串行构图、串行排序、内存带宽与单个巨大仿射空间都可能限制扩展。本轮实现按中心动态分配任务，**没有**进一步把一个巨大仿射空间拆成并行 Gray-code 区间，所以不对所有图承诺线性加速。

原稿的完整 P2 枚举下界仍只限制这种枚举范式。更多内存、多核、不同覆盖，都不会自动证明或否定一般 Hamiltonian parity 的更小指数底数。

## 7. 本轮新增的条件期望实现：只处理相关行

完整 `n×n` 行依赖表中，独立行的记录均为零。保存这些零和每一轮更新所有中心的秩，在实际满秩附近的矩阵上很浪费。本轮进一步将条件计数归一化，再只存真正的行依赖；实现为 `choose_sparse`。

设某中心已通过前 `ℓ` 行的一致性测试，前缀秩为 `r_{q,ℓ}`，其对条件期望的贡献正好是

\[
w_{q,\ell}=2^{\ell-r_{q,\ell}}.
\]

不一致中心贡献零。加入下一行时：

- 若该行独立，`ℓ` 与 `r` 同时加一，两个候选 c 位的贡献都仍为 `w`。
- 若该行相关，唯一一个 c 位让它相容。该候选的贡献变成 `2w`，另一个变成零。

假设当前总条件期望为 `T`。只扫描本行相关且此前相容的中心，把要求 c 位为零的 `w` 加到 `Δ`，要求为一的 `w` 从 `Δ` 减去。于是

\[
E_0=T+\Delta,\qquad E_1=T-\Delta.
\]

因此 `Δ>0` 选一，否则选零；**无需计算或保存 T，也无需扫描独立行中心**。选择后，把不符合依赖的中心标成不相容即可。

每条记录保存中心编号、此前相关行数 `d=ℓ-r`（权重为 `2^d`），以及行依赖导出的一个仿射测试。右端偏移 `d_q` 可在预处理时合并进仿射测试，所以每个中心也不必额外保存该偏移。一个中心在同一行最多有一条记录，各记录的活跃标记更新可以并行。

设全覆盖共有 `R` 条相关行记录，则选择阶段只访问 `O(R)` 条记录。按位操作，至多 `O(nR+nM)` 时间和 `O(nR+M)` 位记录空间，另计覆盖与消元工作区。最坏 `R≤nM`，故仍在 ex2–ex3 的 `O(n³M)` 总时间、`O(n²M)` 空间范围内；这里没有新的更小最坏指数。若实际 `R=O(M)`，缓存可小一个 n 因子。

最终 `kw-sparse-det-bucket` 还在同一次运行内复用相同块长的**确定性**辅助图，避免两张相同的图各构造一次。两块随机图没有进行这种复用，以保留相应期望分析中的独立性。所有构造、复制成本都计入总时间；不存在跨输入的免费预计算。

## 8. 分桶去重不引入错误概率

`kw-lv-bucket` / `kw-det-bucket` 使用固定的整数混合函数把访问向量分到 1024 个桶。相同向量一定进入同一个桶；每桶内部仍进行完整整数排序和相邻相等判断。因此哈希碰撞只让不同向量进入同桶，**不会合并不同解，也没有概率错误**。

程序先用线程私有计数表求桶偏移，再在同一个 OpenMP 团队内散布向量，各桶独立排序和计算 P3。最坏总排序工作仍是 `O(V log V)` 比较；分布倾斜时可能无法获得理想加速。额外数组为 `O(nV)` 位，不能把此优化称为小空间。分桶的用途是移除实际串行排序瓶颈，实验不把固定的 1024 桶视为改变指数底数。

## 9. BH13 基准中第二类前缀的计数细节

本轮直接实现 BH13 Algorithm C 的两个前缀族。第一类是长度 `n-k`、重量 k；第二类是在长度 `n-k-1` 上选 k 个一，再附加最后一位 1，因此重量是 **k+1**。两类分别接一个长度 k 的自由后缀。

在随机自环下，第一类前缀产生的候选解数期望为 `2^k/2^k=1`；第二类为 `2^k/2^(k+1)=1/2`。原文 Lemma 4 同时写成期望恰为一，证明中“恰好有 k 个置一位”对第二类并不成立。每个前缀的期望都至多一，因此 Algorithm C 的 `O*(φ^n)` 上界不受影响。

实现不需要猜测这个常数：对当前已经固定的对角位，只加入其对应的实际活跃行，得到秩 r；令尚未曝光的活跃行数为 u。条件候选数期望就是

\[
2^{k-r-u}
\]

（若已固定方程不相容则为零）。为了用整数精确比较，在决定第 ℓ 个对角位时统一乘 `2^(n-ℓ)`。代码 `bh_count` 正是这一计算，两个前缀族均按实际重量处理。最终再检查所有 P2 行，并支付 P3，因此没有给 BH13 增加覆盖或 ownership 的额外开销。

这个细节不同于 v3 已经说明的 BH13 一般模数公式符号笔误；二者都不推翻 BH13 的奇偶算法。来源文本保存在 sources/BH13.txt（原记录路径：`sources/BH13.txt`），对应 §4、Lemmas 3–6。

## 10. 同样优化 BH13，形成相同空间条件的对照

为了不把指数缓存的收益误归于 KW，最终程序还实现 `bh-det-cache`。对每个 BH 前缀，预处理后缀系数行及其依赖；行的下标保留为原图顶点的下标，因此依赖是对人工对角 c 的一个仿射测试。

第一类前缀的初始期望是 1，第二类是 1/2。将所有条件期望统一乘二，初始权重分别为 2 和 1。固定一个活跃对角位时，独立系数行使权重保持不变；相关行让正确候选的权重翻倍，错误候选归零。不活跃的对角位没有影响。于是与 §7 完全一样，只需扫描相关行记录并比较 `T±Δ`。

这保留 BH13 的指数底数 φ，但消除了其直接实现中按 n 个对角位重复消元的成本。普通位操作下可得 `O(n³φ^n)` 确定性时间、`O(n²φ^n)` 位最坏缓存空间；实际只保存相关行。有限实验还检查选出的每一最终 c 与直接 Algorithm D 相同。

因此应比较两组不同的问题：

1. 保持多项式空间时，BH13 Algorithm D 与 KW 几何块回滚版本；
2. 允许指数缓存时，`bh-det-cache` 与 KW 前缀依赖缓存版本。

本轮的记录压缩与并行技术不是 KW 独有的理论优势。把它同样应用于旧方法，是更可靠的性能归因。
